# Überknall Preamp VST3 — prototype source 0.1

## What this is
A JUCE VST3/Standalone source project for a **preamp-only prototype**:
- DRIVE
- OUTPUT
- HIGH GAIN switch (off by default; Standard is the default)
- No tone stack, no presence/bass/mid/treble controls, no post-drive EQ

The HIGH GAIN switch changes gain in the nonlinear middle stages. It is not a final volume boost. OUTPUT is post-preamp level compensation.

## Important engineering status
This is a **first DSP prototype**, not a transistor-level port of the PCB Guitar Mania circuit and not a validated match to a Bogner Uberschall. It uses a multi-stage, asymmetric soft-clipping model with interstage bandwidth shaping. The PCB Guitar Mania reference schematic is a pedal-inspired circuit, not the proprietary Bogner amplifier schematic.

The first listening test must verify:
1. Raising DRIVE increases harmonic saturation, not only level.
2. Raising the signal level before the plugin (a boost) increases saturation.
3. OUTPUT changes loudness without materially changing the saturation character.
4. HIGH GAIN produces more saturation at matched output level.
5. STANDARD is selected on first load and when parameters are reset.

If a boost only makes it louder, record input/output and inspect the plugin's input level and the nonlinear stage transfer curves before changing the model.

## Build requirements
- Windows 10/11
- CMake 3.22+
- Visual Studio 2022 with C++ desktop workload
- JUCE 7 or JUCE 8 source checkout

Build from a Developer PowerShell:

```powershell
cmake -S . -B build -DJUCE_DIR="C:/JUCE"
cmake --build build --config Release
```

The VST3 and Standalone targets are generated by CMake. Exact install location depends on JUCE/CMake configuration.

## Schematic reference used
PCB Guitar Mania, *Überknall*, Building Docs v1.2 (27 September 2022):
https://pcbguitarmania.com/wp-content/uploads/2019/08/Uberknall-1.2v-Building-Docs.pdf

The v1.2 parts list identifies TL074, two J201s, two SST201s and a BC547B, and documents component changes for its High Gain modification. This prototype does not yet reproduce those component-level interactions. The next engineering pass should map each preamp stage and the documented High Gain resistor changes against the schematic, then refine the DSP model with level-matched measurements.

## Known limitations in 0.1
- No oversampling yet; nonlinear processing can alias at high drive.
- The stage model is intentionally provisional.
- No cabinet simulation, amp power section, tone stack, or speaker IR.
- No compiled binary is included because JUCE and the Windows compiler toolchain are required to build the VST3.
